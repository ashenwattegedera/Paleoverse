# Legacy local model assets

The locally supplied T. rex FBX and texture maps remain here, ignored by Git while their creator/source/license are unknown. They are not used by the active illustration-first application.

Vite now serves `public/`, so `models/` is neither a public directory nor copied into production builds. Do not copy unverified media into `public/`, remove ignore rules, or infer rights from the source-code MIT license.

The original paths and limitations are recorded in `docs/assets/manifest.md` and `docs/animation/viewer-and-rigging.md`. Future 3D is optional and requires an explicit viewer integration with rights-cleared assets.
